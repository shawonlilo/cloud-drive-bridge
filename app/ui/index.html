⬆️ Uploads verify the checksum after transfer: a plain ETag is compared to the file MD5. Multipart ETags are not a plain MD5 — for those we say so and check size only. No silent "verified".

📌 Pinned offline

Pinning warms the rclone VFS cache (or the app offline cache when unmounted) so pinned files open fast and survive short offline periods. Pins are managed by the app, in preference order over normal cache.

Mount as a drive 🌉

Desktop power feature: your bucket becomes a drive letter (Windows) or a folder (macOS/Linux) that every app can use. Mount engine: rclone, configured through environment variables only — it never writes your keys to a config file either.

Checking drivers…
🛡️ Watchdog: if the mount process dies or the drive stops answering, Cloud Drive Bridge remounts it automatically with backoff (5s → 60s). That fixes rclone's known flaky reconnect-after-sleep behaviour. Performance profile baked in: VFS cache full, 128M buffers/chunks, 4 transfers, 8 checkers, 12h directory cache.
